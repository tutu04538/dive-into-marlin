# 基线与测量工具

这里放后续编写的正确性检查、基线驱动、环境采集和结果汇总工具。目前尚无可运行的自定义 benchmark。

首个驱动应完成：

- 查询真实设备信息，解决上游 `bench.py` 对未知 GPU 的 `SMS=-1` / 负数 `ideal` shape 问题，合理控制显存占用。
- 调用固定版本的原始 Marlin；在同一设备和计时口径下对照 FP16 `torch.matmul`。
- 检查每个被测 shape 的正确性，计时阶段排除打包、输入生成和首次编译。
- 允许指定 M/N/K、groupsize、warmup、重复次数和随机种子，输出逐 shape 的延迟与统计量。
- 保存实际加载的模块路径、源码版本、运行命令及环境信息，防止误测其他实验版本。

计时脚本的变化与内核的变化分别记录。原始 benchmark 只计合成数据的运行时间，不作为正确性验证；Laptop 与 Desktop 使用同一套测量定义。
