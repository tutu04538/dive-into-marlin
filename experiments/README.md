# 兼容性适配与优化实验

每项实验建立独立目录，例如 `001-laptop-baseline-compat/`、`002-tile-config/`，包含说明和必要的补丁或源码。它们目前只是命名示例。

实验说明至少包含：

- 基于哪个上游提交，实验类别是兼容性适配还是性能优化。
- 问题、证据和假设；这次改变的主要变量。
- 应用补丁、构建、测试、运行和恢复基线的方法。
- 正确性结果、逐 shape 的性能变化以及退化情况。
- 对应 `results/` 报告的链接和是否采用该改动的结论。

保持 `third_party/marlin` 原样。需要完整工作副本时可放到已忽略的 `experiments/worktrees/`，但必须在实验目录保存可重建该副本的步骤和补丁。复制上游源码时保留许可证和版权声明。
