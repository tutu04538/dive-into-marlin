# 实验结果

这里提交小体积、可审阅的 Markdown 报告和 CSV/JSON 汇总。完整构建日志、原始计时数据和 profiler 输出可保存在 `raw/`，该目录已被 Git 忽略；报告需标注原始数据存放位置。当前没有性能结果。

后续：[2026-10-14 cache hint 根因定位](2026-10-14-cache-hint-root-cause.md)（`ptxas` 优化代码生成异常，最小绕过补丁通过 35 个计算用例；非性能基线）。

建议文件名：`YYYY-MM-DD-5090-laptop-baseline.md`。每份报告至少记录：

| 类别 | 内容 |
| --- | --- |
| 版本 | 本项目提交、上游提交、实验补丁、工作区是否干净 |
| 硬件 | GPU 完整型号、CC、SM 数、显存、功耗限制 |
| Laptop 状态 | 供电、性能模式、温度、时钟、是否出现降频 |
| 软件 | OS、驱动、CUDA Toolkit、PyTorch / CUDA 构建、编译器和构建参数 |
| 复现 | 安装和运行命令、模块路径、随机种子 |
| 负载 | M/N/K、groupsize、布局、dtype、内核配置 |
| 正确性 | 参考权重的构造、误差定义、阈值和实测误差 |
| 测量 | 计时方法、包含的开销、warmup、重复次数、缓存策略 |
| 性能 | 原始 Marlin、FP16 GEMM、优化版的延迟中位数与波动 |

优化加速比定义为 `基线耗时 / 优化版耗时`。与 FP16 GEMM 的比较另列，保持单位一致，并区分 Laptop 和 Desktop。失败的构建或测试也可以形成报告，明确停止在哪一步；不填写推测的测量结果。
